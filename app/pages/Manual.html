BEAT KEY

Get the BPM and key of a beat. Send them where you work.

Get a reading

Link
Paste a YouTube link, press Return. MP3 lands in Downloads, BPM and key in the name.
Open audio
Choose or drop audio files, any number. Arrows page them.
Listen
Live BPM and key from what is playing. Nothing recorded or saved.
Hold
Freeze the reading. Click again to follow.
New song
Clear the listen reading, start fresh.

Listen

Source
System audio or one input. Settings › Listen to.
Channel
One interface channel, or all.
Silence
The reading starts over after 2, 3, 5 or 10 s of silence. NO SOUND · CHECK SOURCE shows until sound returns.

Read the display

BPM
Click: normal, double or half time.
Key
Key heard. Ring and % show how sure.
Top keys
Three likeliest. Click to pin, click again to unpin.
Lights
Green octagon = locked. Amber triangle = unsure. Red circle = working.
Advanced
Adds key wheel, chords, MATCH TO. Click to hear a chord, drag it to a DAW as MIDI.

Send

Send to DAW
BPM and key to the DAW you used last. Send to All DAWs: every open one.
Auto-Tune
Sets key and reference pitch in Auto-Tune and Tune Real-Time. In Tune Real-Time, load the Beat Key preset.
Export MIDI
A .mid with tempo and key, for any DAW.
Rename
Add key + BPM to file names: ask, always or never. Pro Tools files always ask.

Advanced Mode, High Contrast.

When it breaks

Run Doctor
Beat Key menu. Checks downloader, ffmpeg, analyzer.
Report
Help › Send Report. Mail opens with the log attached. No Mail: saved to the Desktop.
Uninstall
Beat Key menu › Uninstall Beat Key… Everything goes to the Trash. Tick Keep my settings to keep them.

Help Mode (Help menu, or the HELP chip): hover anything for a tip. Log: ~/Library/Logs/Beat Key/beatkey.log. Permissions are asked only when a feature needs one: Microphone, Screen & System Audio Recording, Accessibility (typing into Pro Tools, Logic, Studio One).
