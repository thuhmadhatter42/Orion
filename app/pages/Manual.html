BEAT KEY

Get the BPM and key of a beat. Send them where you work.

Get a reading

Link
Paste a YouTube link, press Return. MP3 lands in Downloads, BPM and key in the name.
Open audio
Choose or drop audio files, any number. Arrows page them.
Listen
Live BPM and key from what is playing. Nothing recorded or saved.
Hold
Freeze the reading. Click again to follow.
New song
Clear the listen reading, start fresh.

Listen

Source
System audio or one input. Settings › Listen to.
Channel
One interface channel, or all.
Silence
The reading starts over after 2, 3, 5 or 10 s of silence. NO SOUND · CHECK SOURCE shows until sound returns.

Read the display

BPM
Click: normal, double or half time.
Key
Key heard. Ring and % show how sure.
Top keys
Three likeliest. Click to pin, click again to unpin.
Lights
Green octagon = locked. Amber triangle = unsure. Red circle = working.
Advanced
Adds key wheel, chords, MATCH TO. Click to hear a chord, drag it to a DAW as MIDI.

Plug-in

A file
Drop it in the Beat Key window.
On YouTube
Playing while you record? Listen, from the menu bar.
In a session
Put the plug-in on the track. Play. Key and BPM show. Same faceplate as the app window.
DOWNLOAD
Paste a YouTube link. In Pro Tools, pick where it goes. Elsewhere it is saved and shown in Finder. Needs the Beat Key app.
SEND TO DAW
Set the session tempo. Needs the Beat Key app. The line under the link says the session tempo now.
SEND TO AUTO-TUNE
Key and reference pitch to Auto-Tune. No app needed.
TOP KEYS
Click a key to pin it, again to unpin. Click the BPM for ×2 and ÷2.
ADVANCED
Key wheel and chords. Drag a chord into the session as MIDI.
Formats
Audio Unit: Logic. VST3: hosts that take VST3. AAX: Pro Tools.

Send

Send to DAW
BPM and key to the DAW you used last. Send to All DAWs: every open one.
Auto-Tune
Sets key and reference pitch in Auto-Tune and Tune Real-Time. In Tune Real-Time, load the Beat Key preset.
Export MIDI
A .mid with tempo and key, for any DAW.
Rename
Add key + BPM to file names: ask, always or never. Pro Tools files always ask.

Install the plug-in

Install
In the Beat Key installer, click Customize. Audio Unit, VST3, AAX: pick the ones you use. Quit and reopen your DAW after.
Where
/Library/Audio/Plug-Ins/Components · /Library/Audio/Plug-Ins/VST3 · /Library/Application Support/Avid/Audio/Plug-Ins
Update
Beat Key updates itself. Then Beat Key menu › Update Plug-ins… One password.
Report
REPORT on the plug-in. Mail opens with the plug-in logs attached.
Logs
~/Library/Logs/Beat Key: plugin.log, install.log, beatkey.log (plug-in problems, with the host's name).

Settings

Display
Advanced Mode, High Contrast.
Listen
Source, channel, start over after.
File names
Add key + BPM: ask, always, never.
General
Open at Login. Display colour: the COLOR chip.

When it breaks

Run Doctor
Beat Key menu. Checks downloader, ffmpeg, analyzer.
Report
Help › Send Report. Mail opens with the log attached. No Mail: saved to the Desktop.
Uninstall
Beat Key menu › Uninstall Beat Key… The app and the plug-ins go to the Trash. One password. Tick Keep my settings to keep them. Terminal: sh "/Applications/Beat Key.app/Contents/Resources/uninstall.sh"

Help Mode (Help menu, or the HELP chip): hover anything for a tip. Log: ~/Library/Logs/Beat Key/beatkey.log. Permissions are asked only when a feature needs one: Microphone, Screen & System Audio Recording, Accessibility (typing into Pro Tools, Logic, Studio One).
